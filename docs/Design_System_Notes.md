# Curio — Design System Notes

Status: Early direction

## Personality

Curio should feel:

- Calm
- Focused
- Playful
- Premium
- Minimal

## Visual Direction

- Warm off-white background
- Deep ink text
- Soft violet primary accent
- Warm amber delight accent
- Rounded cards and controls
- Gentle depth instead of heavy shadows
- Motion as guidance, not decoration

## UX Principles

### Curiosity First

The product should make starting a session feel lighter than opening a blank document.

### Completion Over Complexity

Every screen should help the user finish a meaningful learning session.

### AI As Coach

AI should support the user's thinking, not become the main author.

### Visible Progress

Users should always understand where they are in the loop and what remains.

## MVP Components

- Button
- Card
- App shell
- Workspace shell
- Timer display
- Checklist
- Source card
- Key claim card
- Reflection form
- AI feedback card

## Accessibility Direction

- WCAG AA contrast
- Visible focus states
- Keyboard navigable flows
- Reduced-motion support
- No critical information communicated by motion alone
